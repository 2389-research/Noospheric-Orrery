### **Current Project Overview**

- Building multi-agent platform for personalized commerce and workflows
- Team of 5 people including ML expert with commerce/product background
- Incorporated June 2023, all working full-time
- Current focus: Building robust proof of concept before seeking funding
- Early experimental implementation using Discord and Python

### **Technical Architecture & Capabilities**

- Multi-agent system with manager agent coordinating specialized agents
- Knowledge graph backend storing user preferences and context
- Vector database with several million products for discovery
- Key features:
    - Human-in-the-loop capability to bring in expert knowledge
    - Group collaboration functionality
    - Asynchronous task handling
    - Preference stacking for personalization
    - Integration with existing data sources (email, purchase history, etc.)

- Current market favors small checks with revenue expectations
- Differentiation challenges:
    - Basic AI shopping assistants becoming commoditized

    - Large platforms (Amazon, Google) have significant data advantages
- Opportunities:
    - Specialized datasets can outperform general solutions
    - Complex multi-party workflows remain underserved
    - Group purchasing and collaboration use cases
    - Vertical-specific implementations
