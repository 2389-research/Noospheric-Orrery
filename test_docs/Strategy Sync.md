### AI Development Workflow & Philosophy

- Current reality: Doesn’t matter who you are or background - anyone can build technical products now
- Speed transformation: Traditional 2-week sprints became daily demos with 10+ completed items per person
    - Moved to day-long cycles due to agent productivity
    - Traditional Agile processes (standups, retros, sprints) no longer relevant
- Core principle: If experiencing slow development speed, it’s human problem not agent limitation
- Capability claim: Can build literally anything within 6 weeks (with rare exceptions like anti-bot systems)

### Business Model Tensions

- Central challenge: Balancing narrative success vs actual revenue generation
- Venture reality: Signed up for VC path, can’t just build sustainable $3M ARR business
- Growth metrics confusion: Revenue vs users as separate but related KPIs
- Framework needed: Distinguishing between “doing growth” vs “venture vanity metrics”
- Team accountability gap: Everyone says they’ll do growth work, but Dylan and Anonymous consistently don’t execute

### Technical Collaboration Challenges

- Agent collaboration problem: Multiple people can’t effectively work on same codebase with agents
    - Merge conflicts become 2-hour token-heavy processes
    - Solution: Each person owns separate repos rather than collaborative development
- Skill marketplace approach: Any task done twice should become automated skill
    - Process: Build skill → publish to marketplace → team access
    - Philosophy: “Skill issue” if manually repeating any process
- Tool stack: Moved from Notion to Obsidian + shared vault for better agent integration

### Operational Systems & Recommendations

- Fresh Eyes skill: Automated code review after commits, consistently finds important bugs
- Documentation strategy: Write and publish skills as best knowledge transfer method
- Team adoption: Must bring people along gradually or find different roles for resisters
- File system preference: Agents work better with direct file access than cloud APIs
- Mammoth project highlight: 12-14 hour automated development producing 85% complete applications from rough specs
