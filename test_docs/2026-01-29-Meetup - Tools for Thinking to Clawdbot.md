# Meetup: Tools for Thinking to Clawdbot

Thu, 29 Jan 26 · Betaworks NYC

### Personal Knowledge Management Systems & Tools

- Obsidian as foundation for note-taking systems
  - Plain text/markdown files enable flexibility and future-proofing
  - Minimal folder structure recommended over complex organization
  - Key folders: Beliefs (personal principles), Clippings (Wikipedia-style), LLM conversations, Personal notes
  - Rob Hazelfield's migration advice: Start fresh, gradually import old content from separate folder
- Readwise integration workflow
  - Automatic highlighting from articles flows into Obsidian
  - Podcast capture via triple-click on headphones (using Steuart app)
  - BookWise (unreleased Readwise product) expanding into Kindle space
  - "Gardening" process: Manual curation of 20% of content for important insights
- Advanced Obsidian plugins demonstrated
  - Smart Connections: Vector similarity search across notes (700k+ downloads)
  - Smart Chat: AI conversation with personal notes using local models
  - Periodic Notes: Daily templates pulling recent and modified notes
  - Graph view for visual relationship mapping

### Claude Desktop Integration & AI Workflows

- ClaudeBot setup on dedicated Mac Mini
  - Synced 85% of Obsidian vault (excluded sensitive Granola transcripts)
  - "Crash car" philosophy: Separate machine for experimental AI tools
  - Telegram/WhatsApp/iMessage integration for mobile access
- AI-powered daily workflows
  - Automated daily briefings based on calendar and priorities
  - Cron jobs for task rollover between days
  - Context-aware prioritization using personal knowledge base
  - Claims-based note naming: "Tools for thinking are radically changing how we build second brain"
- Security considerations discussed
  - Main risk: Malicious tools with vault access, not cloud model usage
  - Supply chain attacks through third-party plugins
  - Individual threat model assessment needed
  - Privacy vs utility tradeoff on sliding scale

### Emerging Patterns & Philosophy

- Shift from organization to emergence
  - Less manual categorization needed with AI systems
  - Context as important as information content
  - Unstructured systems producing remarkable emergent qualities
  - Steven Johnson's "happenstance machine" concept for serendipitous discovery
- New interaction paradigms
  - Messaging apps as abstraction layer over complex knowledge systems
  - Claude Desktop as "new computer" interaction model
  - Personal computing experience built on individual data patterns
  - Tools enabling "weirdos" to become more effective with personalized systems
