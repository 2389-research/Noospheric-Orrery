# **James / Harper**

Fri, 03 Jan 25 · James Cham

### **Current Project Direction**

- Shifted focus from ecommerce/buying to building a multi-agent network system
- Aims to create a new kind of interaction platform where AI agents and humans work together
- Moving away from pure buying/commerce focus after observing limitations in Perplexity’s approach
- Building initial prototype in Discord/IRC to test core concepts, but long-term vision is for new standalone platform

### **Multi-Agent Architecture Vision**

- Each agent runs as discrete daemon with specific capabilities
- Agents work together in group chat-like environment
- Criticism of current “multi-agent” systems as mostly just prompt chaining
- Knowledge graph implementation with multiple levels:
    - Company-wide knowledge base
    - User-specific knowledge
    - Agent-specific knowledge bases
- Goal is asynchronous operation with ability to “see the work being done”

### **Human-AI Interaction Model**

- Users should be able to “put their hand on the rudder” and guide agents
- Interface should work equally well on mobile and desktop
- Emphasis on making work visible to users rather than black box
- System should support both immediate and asynchronous interaction
- Planning to incorporate human experts alongside AI agents
- Aim for “unhinged” rather than sterile interaction style

### **Technical Implementation Goals**

- Building proof of concept to demonstrate agents working together
- Using Discord/IRC initially due to ease of bot implementation
- Focus on making system work on mobile first
- Implementation of knowledge graphs for context retention
- Emphasis on asynchronous operation capabilities

### **Team & Development Status**

- Working with [[Dylan Richard|Dylan]] (status uncertain)
- Planning to show demo “shortly”
- Taking iterative approach following Mitchell Hashimoto’s philosophy of achievable pieces
- Focused on getting basic agent interaction working before expanding scope
- Currently in prototyping phase

### **Business Strategy Insights**

- Recognition that new platforms typically succeed better than additions to existing networks
- James Cham’s observation that successful new networks require being “radically different”
- Discussion of parallels to early days of Etsy, Tumblr, YouTube
- Acknowledgment that initial platform choice (Discord/IRC) is temporary for testing
