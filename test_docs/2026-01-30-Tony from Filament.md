# Tony from Filament

Fri, 30 Jan 26 · Betaworks

### Community Evolution & Challenges

- BetaWorks founder community has grown significantly over 10 years
  - Started with weekly Thursday gatherings, pizza/drinks, everyone showed work
  - Now runs 2 camps annually with ~20 new teams each time
  - Community spread globally across multiple platforms (Slack, email, LinkedIn, Discord)
- Current challenge: harnessing founder network magic at scale
  - Difficulty maintaining tangible IRL connections
  - Fragmented communication across platforms
  - Need for centralized community hub

### Filament Product Demo & Features

- Tony's background: Very early BetaWorks participant (2009), building networking solution
- Core concept: Professional networking platform connecting siloed communities
  - Global graph of rich professional profiles
  - Cross-channel message sharing between different groups
  - Maintains group trust while enabling information flow
  - End-to-end encrypted DMs with AI concierge
- Key differentiators from existing tools:
  1. Single global identity across all groups/workspaces
  2. Controlled visibility - users control who sees what information
  3. AI agent that summarizes conversations across all channels
  4. Addresses impostor syndrome through contextual Q&A
- Technical architecture: 95% shared codebase (Rust + Uni FFI) across web, iOS, Android, desktop

### Community Engagement Strategy

- Onboarding insights from group discussion:
  - IRL connections crucial - founders want meetups in different cities
  - Email digests drive app engagement (similar to On Deck model)
  - Customizable topic filters (quantum computing, robotics, etc.)
  - Pre-event networking more effective than event apps
- Value proposition for BetaWorks founders:
  - Non-transactional relationship building
  - Location-based founder connections
  - Curated conversation highlights via email
- Integration features: Luma events, profile matchmaking, persistent post-event connections
