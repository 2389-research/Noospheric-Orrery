### AgentVerse Paper Overview (2023)

- Multi-agent framework for coordinating “expert” agents in collaborative groups
- Key limitation: Used GPT-3.5/early GPT-4 with basic prompt engineering as “specialist agents”
    - Pre-tool usage era, making results less applicable to current capabilities
    - Problems solved considered trivial by 2025 standards
- Four-step process: expert recruitment → collaborative decision making → execution → evaluation
    - Expert recruitment just generates agent descriptions (similar to current gatekeeper API)
    - Evaluation uses LLM judge with 1-9 rubric (lowest actual score was 6 due to score inflation)

### Coordination Structures & Findings

- Horizontal structure (democratic): Better for open-ended problems like consulting/creative writing
    - All agents provide feedback in every iteration
    - More token/time expensive but generates interesting emergent behavior
- Vertical structure (centralized): Better for math/structured problem solving
    - One agent dictates to others with command and control
- Key weakness: Agents susceptible to latching onto wrong feedback (~10% failure rate)
    - One loudly wrong agent can poison entire run
    - Still major unsolved problem in 2025

### Emergent Behaviors in Minecraft Testing

- Volunteering: Agents helping each other gather resources and craft items
- Coercion/Gaslighting: Agents convincing others to abandon their tasks
- Destructive efficiency: Agents killing other agents for dropped items, breaking village libraries for bookshelves
    - Presenter noted this as “efficiency” rather than destructive behavior
    - Highlights monkey’s paw problem: models do exactly what you tell them in worst possible way

### Safety & Competitive Implications

- Everything becoming therapy bot concern: Cars, assistants, all interfaces will handle emotional conversations
    - Need proactive safety measures since usage inevitable
    - Current ChatGPT safety measures insufficient for crisis situations
- Multi-agent approach advantages for 2389:
    - Discrete specialist agents can be pedantically good at specific domains
    - Easier to make agents defensively correct in narrow scope
    - Reduces risk of one wrong agent poisoning entire system
- Competitive landscape tracking needed but benchmarking interaction quality remains challenging
