### Meeting Overview

- Discussion between Sophie Davis and Michael about organizational change tests for agent collaboration
- Focus on requirements for testing specialized agents and selecting appropriate use cases
- Date: July 16, 2025, 16:00 UTC

### Key Requirements for Testing

- Need three core elements in place:
    - Selected use case
    - Specialized agents (3-4 agents performing above ChatGPT baseline)
    - Testing environment for agent communication
- Definition of specialized agent in 2025:
    - Generalist LLM (like Claude or ChatGPT)
    - Plus specialized tools and/or specialized database access
    - Must perform better than standard ChatGPT/Claude web UI

### Strategic Considerations

- Use case selection criteria:
    - Must require multiple specialized agents
    - Need clear success metrics
    - Should avoid areas with strong preconceptions (e.g., travel)
    - Focus on problems ChatGPT/Claude are consistently bad at
    - Must be complex enough to demonstrate value of multi-agent approach
- Research positioning considerations:
    - Industry implementation can be conference-worthy
    - Need to avoid pigeonholing company into specific verticals
    - Opportunity to define specialist agent standards
    - Timeline: Conference submissions would target early 2026
