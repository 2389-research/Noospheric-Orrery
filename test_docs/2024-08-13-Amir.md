# Call Notes: Amir and Harper

## Harper's New Venture Idea: AI-Powered Personal Shopper

1. Core Concept:
    - Uses Large Language Models (LLMs) for product discovery and checkout
    - Aims to create a universal shopping cart across all merchants
    - Would handle the entire purchasing process on behalf of users
2. Key Features:
    - Product discovery using semantic search and vector databases
    - Automated checkout process using LLM-powered browser agents
    - Potential for discounts through affiliate partnerships or direct merchant relationships
3. Current Progress:
    - Some checkout functionality working
    - ~900k products in database for searching
    - Experimenting with discovery processes
4. Unique Selling Points:
    - LLMs come with product reviews built-in, aiding in smart recommendations
    - Potential to save users time on research and comparison
5. Challenges:
    - User adoption identified as the primary hurdle
    - Need to demonstrate clear value proposition to users

## Amir's Feedback and Suggestions

6. Expanded Functionality:
    - Include subscription optimization (e.g., managing and reducing recurring costs)
    - Assist with broader financial management (insurance, healthcare costs)
    - Provide financial education, especially for younger generations
7. User Acquisition Strategies:
    - Focus on pain points: "If you gave me a subscription optimizer, I would probably install your bot"
    - Emphasize cost-saving potential to drive adoption
8. Additional Features:
    - Create a feed of interesting products based on user preferences
    - Allow users to follow and view others' shopping habits (similar to eToro for stocks)
    - Implement a social component for sharing deals and earning affiliate revenue
9. Monetization Ideas:
    - Charge a percentage of money saved for users (e.g., 10% of optimized costs)
    - Utilize affiliate marketing and allow users to earn from referrals
