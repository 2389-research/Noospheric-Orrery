### **Character Strategy & User Segmentation**

- Segmentation methodology proposed
    - Prioritize user verticals by willingness to pay vs. market size
    - Define functional, emotional, and interaction needs per segment
    - Score agent functions/teams for relevance to each segment
- Agent personality system framework
    - Grid of traits mapped to segment needs
    - Bundle traits into universal archetypes (paladin, troll concepts)
    - Deploy characters in marketing content with testing/iteration
- Line art vs. 3D decision matrix
    - Line art: modular, vector-based, simple visual language, easy reproduction
        - Signals “easy, simple, fun” - toy and tool combined
        - Risk: need to define what makes “little boxes with eyes” unique
    - 3D art: richer visuals, more alluring, emotional benefits from soft textures
        - Better for lifestyle imagery integration, sidesteps uncanny valley
        - More laborious, less animation flexibility without investment
    - Recommendation: table 3D for now, use for general audience launch materials later
