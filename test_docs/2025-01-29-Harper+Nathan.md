- Vibe is a combination of brand and psychology

### **Expert Mode and User Interface**

- Expert mode can be implemented via second-order game theory
- Aardvark example: showing multiple answers broke the experience for answerers, but worked for receivers who understood the system
- Long-term consideration: Should there be one universal UI?
- Concept of a hyper-personalized UI layer sitting on top of everything at the OS level
