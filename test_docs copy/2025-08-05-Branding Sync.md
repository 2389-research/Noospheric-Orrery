# **Branding Sync**

Tue, 05 Aug 25

### **Development with AI Agents**

- Agent-driven development works similarly to traditional development
    - Agents handle most coding tasks
    - Still requires human oversight like managing junior programmers
    - Need to check for “stupid assumptions” and provide corrections
- Process improvements needed
    - Better input quality = better output (e.g., feeding single typography page vs full PDF)
    - Agents work myopically, missing grand scheme consistency
    - 80% of time faster than human developers, 20% requires manual intervention

### **CSS and Design System Challenges**

- Agent-generated CSS lacks maintainability and consistency
    - Hard-coded values (e.g., yellow colors) instead of design system variables
    - Inconsistent styling across components
- Current solutions being tested
    - Breaking down into smaller SCSS files (grid file, design system components)
    - Using design system references to avoid inline classes
    - Still requires manual review and simplification
- Tooling gaps
    - Tailwind makes agent markup easier but reduces consistency
    - CSS linting tools less developed compared to general code linting

### **Sprite Character System Progress**

- Character generation capabilities
    - 18 different hair/accessory options from Figma
    - Multiple body sizes, colors, arm/leg variations
    - Can generate ~1.4 million unique characters
- Future animation considerations
    - May need separate states for eyes (open/closed) and mouths (excited/neutral)
    - Current system treats all variations as distinct rather than states
    - Will reassess when adding animation functionality
