- Visitors Premium package covers all requirements
    - Preregistration capabilities

    - NDA signing functionality

- Host notification methods: SMS, email, push notification
- Flow is fully customizable - can remove host notification step if needed
    - Could provide access codes directly to guests
    - Include navigation instructions to floor
